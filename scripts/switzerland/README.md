# Switzerland batch (original scripts)

These are the draft scripts used for the first batch, before the generic pipeline
(`scripts/collect.py`, `curate.py`, `download.py`, `load.py`). They are kept for
provenance. They use Wikimedia Commons categories such as
`Featured pictures of Switzerland`, `Quality images of Switzerland` and
`Images from Wiki Loves Earth 2022 in Switzerland`, and write their candidates to
`/tmp`. The current pipeline supersedes them.
